# Loan Risk Analysis & Prediction Project

## 📌 Project Overview
This project analyzes loan applicant data to understand credit risk patterns and build a machine learning model to predict loan risk. The workflow demonstrates an end-to-end data analytics pipeline using Python, SQL, Excel, and Machine Learning.

---

## 🛠 Tools & Technologies
- Python (NumPy, Pandas, Scikit-learn)
- SQL
- Excel (Dashboards)
- Matplotlib & Seaborn
- Jupyter Notebook

---

## 📂 Project Workflow
1. Raw data exploration and understanding  
2. Data cleaning using NumPy  
3. Feature engineering using Pandas  
4. SQL-based analysis for business insights  
5. Data visualization for risk patterns  
6. Machine learning modeling and evaluation  
7. Excel dull same analysis and dashboard for stakeholder reporting
